## Sobre mí

Comencé mi carrera en la operación de reparto y, a partir de los problemas que veía a diario, fui construyendo soluciones: primero macros en Excel, luego indicadores de BI, integraciones con SAP, un Data Warehouse corporativo y aplicaciones propias. Hoy gestiono proyectos de TI y sigo desarrollando.

Ese recorrido me dio un perfil **híbrido funcional-técnico**: entiendo el proceso de negocio antes de escribir la primera línea de código. No me conformo con el trabajo rutinario; si una tarea se repite, busco la forma de automatizarla.

- **Analista de Proyectos TI.** Gestión de proyectos de tecnología con proveedores externos: un sistema de etiquetado y trazabilidad integrado con SAP y una aplicación móvil, y la automatización de inventarios con transacciones SAP. Planificación y seguimiento en Azure DevOps y Microsoft Teams, planes de prueba y validación de entregables.
- **Analista de Operaciones Comerciales.** Key User SAP (SD/MM/ABAP) y Data Owner del Data Warehouse corporativo. Ciclo completo de mejoras del ERP, desde el diagnóstico hasta el pase a producción, migración de los indicadores del área de Excel a Power BI y desarrollo de herramientas internas.
- **Controlador de Operaciones Comerciales.** Automatización con VBA (macros, formularios CRUD, complementos de Excel), extracción asíncrona de datos desde SAP GUI y seguimiento del ciclo de vida de las entregas, del despacho a la facturación.
